Las busquedas son de vital importancia para la resolucion de problemmas, se hacen estrategias para
encontrar las soluciones a los problemas, y hay tipos:

* Una busqueda ciega es cuando no tiene informacion y solamente 
consiste en tener un patron a seguir.
* Heuristica es una busqueda con informacion y que se aplica para 
tomar desiciones mas efectivas
* Algoritmos de optimizacion y de busqueda local se hace cuando 
se realizan busquedas grandes

Normalmente se aplican estas busquedas a juegos que son para 1 jugador contra una computadora,
el cual busca la forma de ganarle a una computadora, ejemplos de esto es el Gato, y el Ajedrez
usando algoritmos como Minimax, osea, la ganancia de uno es la perdicion del otro.
